# Audio assets

All audio files currently used by the game are free/open assets suitable for this prototype.

## Music

- `music/menu.ogg`: `Cunning plan (short seamless loop)` by congusbongus, OpenGameArt, CC0. Source: https://opengameart.org/content/cunning-plan-short-seamless-loop
- `music/game.ogg`: `Head in the Sand (seamless loop)` by congusbongus, OpenGameArt, CC0. Source: https://opengameart.org/content/head-in-the-sand-seamless-loop

## Sound effects

- `sfx/click.ogg`, `sfx/start.ogg`, `sfx/clean.ogg`, `sfx/prize.ogg`: selected files from `UI Audio` by Kenney, CC0. Source: https://kenney.nl/assets/ui-audio
- `sfx/spray.wav`: `Laser_shooting_sx` by teckpow, OpenGameArt, CC0. Source: https://opengameart.org/content/lasershootingsx
- `sfx/dirt-hit.oga`: selected from `Thwack Sounds` by AntumDeluge / Jordan Irwin, OpenGameArt, CC0. Source: https://opengameart.org/content/thwack-sounds

## Notes

- Browser autoplay requires a user gesture, so music starts after the first button/key press.
- Disable audio quickly with `?audio=0` or by setting `GAME_CONFIG.audio.enabled = false`.
- Original downloaded packs are kept in `source/` for traceability.
