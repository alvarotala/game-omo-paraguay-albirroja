# Fuentes

Este juego incluye Barlow Condensed para que la tipografia se vea igual en macOS y Raspberry Pi OS, sin depender de fuentes instaladas localmente.

- `BarlowCondensed-Bold.ttf`
- `BarlowCondensed-ExtraBold.ttf`

Fuente: Google Fonts, Barlow Condensed. Licencia: SIL Open Font License 1.1, ver `OFL.txt`.
